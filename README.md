<h1>Sight Dominate</h1>

4+4 Line 리듬 게임으로
입력 범위를 이동시키는 것이 특징인 게임이다.

<img width="1280" height="720" alt="아이디어" src="https://github.com/user-attachments/assets/d963c309-d25a-413d-a307-c46fcdc61bbe" />
<설명용 이미지 1><br><br>

현재 기준으로 3,4,5,6라인에서 나오는 노트를 처리할 수 있지만<br>
이후 나오는 7,8라인에서 나오는 노트는 처리할 수 없다.<br>
이때 플레이어는 입력 라인을 옮겨 처리할 수 있는 것이다.<br>
<br><br><br><br><br>

게임의 난이도(또는 난도 또는 어쩌구저쩌구) 조절 방식은<br>
제목에도 나와있듯 리딩으로 잡을 생각입니다.<br>
노트를 보고 해석을 어렵게 하는 게임<br><br>

하지만 이를 '리딩이 어려운게임'이 아니라<br>
'사람마다 치는 방식이 다른 게임'을 만들고자 합니다.<br><br>

주로 모바일 게임을 하는데<br>
성과를 내는 것도 재밌지만<br>
가장 재밌을 때는 쉬운 손 배치(또는 멋있는 손 배치)를 발견했을 때 입니다.<br>
이런 플레이를 컴퓨터에서도 느껴보고 싶었습니다.<br><br>

라고 적었지만...<br>
아 사람 리겜 경력이 아주 초라하다!<br>
리듬게임 관련해서 했던 것이 뭐 없습니다. ㅋㅋ...<br>
그나마 옛날에 채보 깔짝대던거...<br><br>

뭐어... 잘 하는게 뭐 중요합니까(?)<br>
내가 만들고 싶다는데<br>
내가 좋아한다고<br>
